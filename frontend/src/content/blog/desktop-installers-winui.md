Product law is **desktop preferred + web parity** — same SPA, one Standard
licence. The preferred host is a **local-first desktop node** (WinUI 3 shell):
local Postgres, worker, and Ollama; metadata syncs through the cloud hub when
licensed. Browser workspaces remain first-class at `studio.aorms.in` and
`consultancy.aorms.in`.

## Where to get builds

Signed Windows installers appear on
[`/downloads`](/downloads) when a release publishes a HTTPS URL and sha256 in
the update manifests. Until that gate is green, the portal keeps **honest web
CTAs** — we do not offer unsigned overnight artifacts or retired Lite/Pro
Manager Setup.exe links.

## What stayed retired

- Lite / Pro / Community **Manager** installers
- Separate **Estimate** desktop app (estimating stays in-product)
- Tauri packaging paths — canonical shell is WinUI 3
