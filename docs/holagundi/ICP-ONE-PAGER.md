## Who buys

Indian **architecture** consultancy firms, roughly **5–50 people**.

**Not for:** engineering consultancies, contractors, PMC portfolios, construction
execution ERP, warehouses, running-account bills, or tenders.

---

## Job to be done

Replace WhatsApp + email + Excel + generic PM + ad-hoc GST with one **office
operating record**: fees → delivery → revisions → site supervision → invoices →
portals.

**Wedge line:** *Operating system for architecture consultancies in India*.

---

## Why AORMS (not Excel / ArchiO / Monograph)

| Need | AORMS |
|---|---|
| India money | Paise, COA fees, GST/TDS, FY April |
| Site supervision (architect-side) | Drawings, transmittals, snags, instructions, progress |
| Built-in AI | **ESTI** — answers only from the firm's own validated repositories |
| One unified office hub | Web-only SPA, single sign-on, no per-app logins |
| External proof | Client / consultant / contractor / site portals |
| Switching cost | Web-only, one login, no installers · one Standard licence |
